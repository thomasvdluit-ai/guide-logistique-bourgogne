# Guide Logistique Bourgogne

Site éditorial expérimental, prêt à être publié avec GitHub Pages.

## Avant publication

1. Publier le dépôt avec GitHub Pages depuis la branche `main` et le dossier racine.
2. Ajouter l'URL dans Google Search Console puis envoyer `sitemap.xml`.

## Événements disponibles dans la dataLayer

- `cta_click`
- `generate_lead`
- `scroll_depth`
